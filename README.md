# Styling Paradigms Assignment

Two small React exercises in one application:

- **Exercise 1 — Tailwind CSS:** a responsive product dashboard with reusable
  product cards, configured theme values, and hover, focus, and disabled states.
- **Exercise 2 — Vanilla Extract:** reusable `Button`, `Card`, and `Badge`
  components with typed variants and shared design tokens. Vanilla Extract
  emits the component styles as CSS during the production build.

## Run locally

```sh
npm install
npm run dev
```

The dashboard uses one, two, and three columns at the small, medium, and large
Tailwind breakpoints. The two exercises are in `src/exercise-1-dashboard` and
`src/exercise-2-library`.
